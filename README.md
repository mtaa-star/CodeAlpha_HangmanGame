

\# CodeAlpha Hangman Game



\## Project Overview

This is a simple text-based Hangman game developed using Python

as part of the CodeAlpha Python Programming Internship.



\## Features

\- Random selection from five predefined words

\- Six incorrect guesses allowed

\- One-letter-at-a-time guessing

\- Validation of user input

\- Detection of repeated guesses

\- Win and lose messages



\## Requirements

\- Python 3



\## How to Run

1\. Install Python 3 if it is not already installed.

2\. Open Command Prompt in the project folder.

3\. Run the following command:



&#x20;  py hangman.py



\## Concepts Used

\- Variables and strings

\- Lists

\- Random selection

\- While loops and for loops

\- If-else conditions

\- User input and output

\- Functions
